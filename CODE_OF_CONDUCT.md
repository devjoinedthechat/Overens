# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be considerate, argue about the work and not the person, and assume good faith. Harassment, insults and personal attacks are not accepted in issues, pull requests or anywhere else the project lives.

To report a problem, write to the maintainer privately through the [form for a private advisory](https://github.com/devjoinedthechat/Overens/security/advisories/new), which takes any private report. Or report it to GitHub through its [form for reporting abuse](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam). Reports are kept confidential.
